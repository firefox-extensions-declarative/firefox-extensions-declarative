## Building
Run `npm install` and then `npm run build`. The XPI is located at `Youtube-shorts_block_v<version>_fx.zip`.

## Options

### `isEnable`
Whether to enable Youtube-shorts block.
Type: `boolean`  
Default: `true`  

### `isHideTabs`
Whether to hide the Youtube Shorts tab.
Type: `boolean`  
Default: `false`  

### `isHideVideos`
Whether to hide Youtube Shorts.
Type: `boolean`  
Default: `true`
